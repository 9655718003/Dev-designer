Android மொபைலில் புதிய ஆடைகளைச் சேர்க்கும் பக்கம்

முதல் முறை மட்டும் – GitHub இணைப்பு

GitHub Fine-grained Personal Access Token உருவாக்கி இங்கே உள்ளிடவும். Token இந்த Browser session-ல் மட்டும் இருக்கும்; இணையதளக் கோப்பில் சேமிக்கப்படாது.

Token உருவாக்குவது: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Repository access: Only select repositories → Dev-designer. Repository permissions → Contents: Read and write. Token-ஐ Copy செய்து கீழே ஒட்டவும்.

இன்னும் GitHub இணைக்கப்படவில்லை.
பாதுகாப்பு: Token-ஐ யாரிடமும் பகிர வேண்டாம். உங்கள் சொந்த மொபைலில் மட்டும் பயன்படுத்தவும். வேலை முடிந்ததும் GitHub Settings-ல் Token-ஐ revoke செய்யலாம்.

புதிய பொருளைச் சேர்க்கவும்

மொபைலில் இருந்து நேரடியாகப் புகைப்படம் தேர்வு செய்யலாம். பதிவேற்றத்திற்கு முன் படம் சுருக்கப்படும்.

பொருள் விவரங்களை நிரப்பி வெளியிடலாம்.
